## 正在做 · Prelude

Prelude 是嵌入 DeepSeek Harness 的提示词辅助插件。

希望让每个 DSH 用户，都能像提示词工程师一样清晰地表达需求。

Prelude 帮助你发现需求中的遗漏、理解提示词方法，并比较原稿与改写稿。是否补充、如何修改、最终采用哪一版，都由你决定。

[Prelude 已开放预览](https://github.com/dbcaskml183-dotcom/dsh-prelude)。[查看安装说明](https://github.com/dbcaskml183-dotcom/dsh-prelude/blob/main/docs/installation.md)，或先看[一次改写示例](https://github.com/dbcaskml183-dotcom/dsh-prelude#先看一次改写)。
